# Answely – AI Answers for Site Search

Short AI answers with sources from your own pages, right in your site search. Processing in the EU.

- Shows a short answer above the results of the WordPress search, with links to the pages that back it; says so when no page backs an answer
- Answer field block and `[answely]` shortcode, with a fallback to the normal search results page
- Follows the language of each page (Polylang and WPML) or a fixed language
- Optional waiting for consent before the box fetches its configuration or answers: IAB TCF v2, consented.eu and the WP Consent API
- Optional content sync through the Answely Push API and, with WooCommerce, "My orders" for signed-in customers (order data stays on your site)
- No cookies, no visitor identifier

Needs an Answely account (free plan available). Requires WordPress 6.3 and PHP 7.4. Details in [readme.txt](readme.txt).
